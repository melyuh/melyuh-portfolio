## Zshのセットアップ

今回は標準のBashからZshを変更してみます。

```bash
# パッケージリストの更新
sudo apt update

# Zshのインストール
sudo apt install zsh

# デフォルトシェルをZshに変更する
chsh -s $(which zsh)
```

!!! note
    シェルをZshに変更した後は、一度WSLのターミナルを閉じて、もう一度`wsl`コマンドで入り直すと設定が確実に反映されます。

### Oh My Zshのインストール

Oh My Zshとは、Zshを管理するフレームワークです。
これを導入するだけでZshをかっこよくできます。

{{ link_card(url="https://ohmyz.sh/") }}

公式のコマンドでインストールします。

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

### 追加するZshプラグイン

#### zsh-autosuggestions

過去の履歴から予測変換してくれます。

```bash
# インストールコマンド
git clone https://github.com/zsh-users/zsh-autosuggestions ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions
```

#### zsh-syntax-highlighting

コマンドを色分けしてくれます。

```bash
# インストールコマンド
git clone https://github.com/zsh-users/zsh-syntax-highlighting.git ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting
```

#### z（標準搭載）

ディレクトリを瞬間移動できます。

一度でもアクセスしたことのあるディレクトリを記憶し、深い階層のフォルダでも`z <ディレクトリパスのフォルダ名>`と実行するだけで瞬間移動できます。

#### sudo（標準搭載）

あとから`sudo`をつけられます。

コマンドを打ち終わった後に「sudoつければよかった」というとき、`Esc`キーを**2回連続で押す**だけで、一番手前に`sudo`を付け足してくれます。

### Zshプラグインの有効化

`.zshrc`を開きます。

```bash
nano ~/.zshrc
```

`plugins=(git)`を探し、プラグインを追加します。

**Before**:

```bash title="~/.zshrc"
plugins=(git)
```

**After**:

```bash title="~/.zshrc"
plugins=(git zsh-autosuggestions zsh-syntax-highlighting z sudo)
```

!!! note
    `Ctrl+O`→`Enter`で上書き保存、`Ctrl+X`で終了します。

設定を反映させます。

```bash
source ~/.zshrc
```

## Homebrewのセットアップ

{{ link_card(url="https://brew.sh/ja/") }}

linuxbrewはHomebrewに統合されて、WSLでも使えるようになってます。

公式のコマンドでインストールします。

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

`brew -v`でバージョンが表示されれば、インストール成功です。

### Homebrewのパスを通す

```bash
echo 'eval "$(/home/linuxbrew/.linuxbrew/bin/brew shellenv)"' >> ~/.zshrc
source ~/.zshrc
```

### ビルドツールのインストール

linuxでHomebrewを使うにあたって、必要なツールをインストールします。

```bash
sudo apt-get install build-essential
brew install gcc
```

## miseのセットアップ

miseとは、開発ツールのバージョン管理ツールです。

Pythonなどのプログラミング言語やClaude CodeといったAIツールなどもこれで管理できます。

{{ link_card(url="https://mise.jdx.dev") }}

```bash
# インストールコマンド
brew install mise
```

`mise -v`でバージョンが表示されれば、インストール成功です。

### miseの自動有効化

```bash
echo 'eval "$(mise activate zsh)"' >> ~/.zshrc
echo 'export PATH="$HOME/.local/share/mise/shim:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

### config.tomlの編集

コンフィグファイルを開きます。

```bash
nano ~/.config/mise/config.toml
```

以下を追加してください。

```toml title="config.toml"
[settings]
minimum_release_age = "14d"         # (1)!
experimental = true                 # (2)!
disable_backends = ["asdf", "vfox"] # (3)!
```

1. 最新バージョンがリリースされてから14日間はインストール対象外
2. miseの実験的機能を有効化
3. セキュリティ上の懸念から、プラグインシステムである`asdf`と`vfox`を無効化

!!! note
    `Ctrl+O`→`Enter`で上書き保存、`Ctrl+X`で終了します。

## GitHub CLIのセットアップ

```bash
# インストールコマンド
mise use --global gh

# 初回認証
gh auth login
```

`gh auth status`で認証できているか確認します。

## Tips：チートシート

### Homebrew

パッケージ（ソフトウェア）のインストールや管理を行うコマンドです。

| コマンド | 説明 |
| --- | --- |
| `brew search <パッケージ名>` | パッケージを探す |
| `brew info <パッケージ名>` | パッケージ詳細を確認 |
| `brew install <パッケージ名>` | パッケージをインストール |
| `brew uninstall <パッケージ名>` | パッケージをアンインストール |
| `brew list` | インストール済みのパッケージ一覧を表示 |
| `brew update` | Homebrew本体を更新 |
| `brew upgrade` | インストール済みのパッケージを更新 |
| `brew cleanup` | 不要な古いファイルを削除 |
| `brew autoremove` | 不要な依存関係（関連パッケージ）を削除 |
| `brew doctor` | 環境に問題がないか確認 |

### mise

Node.jsやPythonなど、プログラミング言語のバージョンを管理するためのコマンドです。

| コマンド | 説明 |
| --- | --- |
| `mise ls-remote <ツール名>` | インストール可能なバージョン一覧を表示 |
| `mise use --global <ツール名>@<バージョン>` | ツールをインストール&有効化（システム全体） |
| `mise use <ツール名>@<バージョン>` | ツールをインストール&有効化（現在のフォルダのみ） |
| `mise install` | 設定ファイルからツールを一括インストール |
| `mise ls --global` | インストール済みのツール一覧を表示（システム全体） |
| `mise ls --local` | インストール済みのツール一覧を表示（現在のフォルダのみ） |
| `mise upgrade` | インストール済みのツールを更新 |
| `mise unuse --global <ツール名>` | ツールを無効化（システム全体） |
| `mise unuse <ツール名>` | ツールを無効化（現在のフォルダのみ） |
| `mise prune` | 不要な古いファイルを削除 |
| `mise doctor` | 環境に問題がないか確認 |

### GitHub CLI

ターミナルから直接GitHub操作を行うためのコマンドです。

| コマンド | 説明 |
| --- | --- |
| `gh auth login` | GitHubにログイン |
| `gh auth status` | ログイン状態を確認 |
| `gh repo create` | リポジトリを作成 |
| `gh repo clone <リポジトリ名>` | リポジトリをクローン |
| `gh repo view --web` | リポジトリをブラウザで開く |
| `gh issue list` | Issue一覧を表示 |
| `gh issue create` | Issueを作成 |
| `gh pr list` | プルリクエスト一覧を表示 |
| `gh pr status` | 自分のプルリクエストの状況を確認 |
| `gh pr checkout <番号>` | 指定したプルリクエストのブランチをローカルに取り込む |
| `gh pr create` | プルリクエストを作成 |
| `gh pr review` | プルリクエストをレビュー |
| `gh pr merge` | プルリクエストをマージ |
| `gh auth logout` | GitHubからログアウト |
